По source:

observed — система сама наблюдала это через входные данные.
inferred — система вывела это сама по косвенным признакам.
told — кто-то сообщил это напрямую.
imported — загружено из стартового набора/внешней базы.
generated — создано внутренним процессом, например консолидацией или генератором гипотез.
self — связано с внутренним личным опытом/самостью.
unknown — источник неизвестен или старый формат без источника.



По status:

hypothesis — возможно так, но уверенности мало или мало подтверждений.
confirmed — связь хорошо подтверждалась.
conflicted — есть противоречивые данные.
deprecated — старое знание, лучше не использовать как актуальное.
disabled — связь временно выключена, но не удалена.
